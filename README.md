# GmailActions

Quick notification actions for the official Gmail app on iOS (Dopamine rootless, iOS 15+).

Adds buttons when long-pressing or expanding mail notifications from the Lock Screen, Banner, or Notification Center, configurable in Settings.

### Actions
- Mark as Read
- Mark as Read & Archive
- Mark as Read & Delete
- Toggle stock buttons (Archive, Trash, Reply, Reply All)

Changes in Settings apply immediately without a respring.

### Installation
Download the latest `.deb` from the [Releases](https://github.com/teebee1337/GmailActions/releases) page and install it with Sileo, Zebra, or Filza.

### Building
```bash
make package FINALPACKAGE=1
```
